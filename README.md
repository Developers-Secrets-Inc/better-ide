# Better IDE

> [!WARNING]  
> 🚧 This project is still in early development. Expect frequent changes and incomplete features.

## About

**Better IDE** is a headless open-source IDE for the web.  
It provides the building blocks you need to create custom development environments:  

- 📂 **File system** – virtual files & folders.  
- 💻 **Terminal** – sandboxed command execution.  
- ✍️ **Code editor** – pluggable, language-aware editing.  
- ⚡ **Compilation support** – run JavaScript, TypeScript, and Python.  
- 🧩 **Headless architecture** – integrate your own UI or workflows.  

With Better IDE, you can build platforms similar to **Replit**, **CodeSandbox**, or educational coding tools — but fully open-source and customizable.
